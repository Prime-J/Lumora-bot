# 🎨 Lumora Art Bible — Roblox Icon Prompt Library

The complete icon prompt set for Lumora: **15 fighting styles**, **17 scrolls**,
**101 Mora species**, and **3 faction emblems** (+1 neutral). Every icon is a
**square 1:1 game icon** for the WhatsApp bot *and* the future Lumora Roblox
game.

---

## How to use this file

1. Pick a set and an entry (style / scroll / Mora / emblem).
2. Copy its prompt into an image generator (Midjourney, DALL·E, Stable
   Diffusion, Flux, Leonardo, etc.).
3. Generate at square aspect ratio (1:1), high detail, **no text**.
4. Save the result at the path given for that entry — the bot picks it up
   automatically, no code changes needed:

| Set | Bot folder | File name |
|---|---|---|
| Fighting styles | `assets/styles/` | `<style_id>.png` (e.g. `tenebris.png`) |
| Scrolls | `assets/scrolls/` | `<scroll_id>.png` (e.g. `caligo_vellum.png`) |
| Mora species | `assets/mora/` | `<id>-<name>.png` (e.g. `001-nylon.png`, `096-zovax.png`) |
| Faction emblems | `assets/factions/` | `harmony.png` / `purity.png` / `rift.png` / `kael.png` |

---

## Global art rules (apply to every icon)

- **Square 1:1**, high detail, painterly semi-realistic game-art style.
- **No text, no watermark, no letters** — even rune-like marks are decorative;
  no real words anywhere.
- **Readable at 64×64 px**: one central subject, strong silhouette, no clutter.
- **Dark vignette edges** on character/creature icons; element accent lights the
  subject.
- **Faction color language** applies to anything with a faction (styles, scrolls
  with faction seals, faction emblems):

| Faction | Dominant hue | Accent | Mood |
|---|---|---|---|
| 🌿 Harmony | greens, teals, warm earth | moss, bronze | life, calm, growth |
| ⚔️ Purity | iron-grey, white, steel | bone, cold blue | order, discipline, cold |
| 🕶️ Rift | black, deep indigo | violet, pale eye-glow | mystery, danger, hunger |
| Any (no faction) | element's natural hue | neutral | varied |

- **The Rift's "hungry violet"** is the shared visual thread for everything Rift
  or corrupted: violet rim-light on black.

## Composition templates

There are three icon shapes in Lumora — pick the template that matches the set:

> **Character icon** (styles, Mora): *"Square game icon, single central
> [figure/creature], [element effects], [faction palette], dramatic lighting,
> bold rim light, dark vignette edges, clean silhouette readable at small size,
> painterly semi-realistic game-art style, no text, no watermark, centered
> composition, 1:1."*

> **Object icon** (scrolls): *"Square game icon, single central [parchment
> object] floating slightly angled, [material and closure], [element aura],
> [rarity treatment], dramatic lighting on a [backdrop], clean silhouette
> readable at small size, painterly semi-realistic game-art style, no text, no
> watermark, centered composition, 1:1."*

> **Emblem icon** (factions): *"Square game icon, single central [sigil/crest]
> engraved or embossed, [symbol], [faction palette], [material surface], bold
> rim light, dark vignette edges, symmetrical heraldic composition readable at
> small size, painterly semi-realistic game-art style, no text, no watermark,
> centered, 1:1."*

# PART C — The 101 Mora Species

*Art: `assets/mora/<id>-<name>.png` — character icons.* One icon per species,
organized by element. **How to compose a Mora icon:**

```
FINAL PROMPT = TYPE RECIPE (below) + RARITY TREATMENT + FORM (from that
type's table) + the character-icon template from the top of this file.
```

The type recipe gives the shared look of the whole family (so a Nylon and an
Aquatyr read as the same element at a glance); the form line in each table
describes that one species; the rarity treatment controls how grand the icon is.

## Rarity treatments (escalate in this order)

| Tier | Treatment |
|---|---|
| common | muted single-color backdrop, simple pose, flat lighting, small scale |
| uncommon | two-tone backdrop, one glowing accent, slight rim light |
| rare | dramatic elemental backdrop, strong rim light, particles (sparks/leaves/foam) |
| epic | full element aura, dynamic action pose, environmental effects |
| legendary 🔥 | ascension treatment: radial light, crown-level glow, particles + aura + rays, oversized presence |

Legendary **full-merge** species (marked 🔥 in the table) are the game's gods —
give them a throne-level icon: radial divine light behind, unmistakable
dominance, no other subjects.
